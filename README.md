# turing-fraude-detector
Projeto da disciplina de Teoria da Computação. Implementa uma máquina de Turing que compara o valor de uma transação com um limite em unário e a classifica como normal ou anômala, e confronta os resultados com o Isolation Forest (aprendizado não supervisionado) na base HI-Small, de transações financeiras com rótulos de lavagem de dinheiro.
